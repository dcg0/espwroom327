02 / HARDWARE

¿Qué hace cada pieza?

ESP32 WROOM y adaptador ELM327 Bluetooth son componentes distintos que pueden participar en una solución OBD-II. La compatibilidad depende del hardware y del software.

COMPONENTE 01

ESP32 WROOM · ejecuta el programa

Microcontrolador que puede ejecutar el firmware y alojar una interfaz web local. El teléfono podría conectarse a su red Wi‑Fi, de acuerdo con la configuración del proyecto.

La placa exacta depende del firmware y de la compilación.
COMPONENTE 02

ELM327 Bluetooth · enlace OBD-II

Adaptador que se conecta al puerto OBD-II y puede actuar como interfaz para consultas compatibles, como parámetros, códigos DTC o VIN.

La compatibilidad varía según adaptador y vehículo. Ilustración genérica; no es recomendación de compra.
